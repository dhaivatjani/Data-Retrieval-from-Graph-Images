# Data

This folder contains curated data for the GitHub version of the project.

## Structure

```text
data/
├── samples/
│   ├── bar/
│   ├── line/
│   └── scatter/
└── synthetic/
    ├── bar/
    ├── line/
    └── scatter/
```

## `samples/`

Contains only a sample images per graph type. This keeps the repository lightweight while still allowing readers to understand the input/output format.

## `synthetic/`

Contains the synthetic ground-truth CSV files used for validation.
